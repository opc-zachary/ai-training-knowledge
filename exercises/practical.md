# Practical Capstones

## Capstone A — Client research package

Deliver:

1. research brief;
2. source ledger;
3. claim-evidence table;
4. 10-page decision report;
5. executive summary;
6. contradiction review;
7. QA report.

Success is measured by traceability and decision usefulness, not report length.

## Capstone B — Author-led content system

Using authorised samples:

1. build author voice system;
2. create three topic briefs;
3. draft three different structures;
4. evaluate identity and originality;
5. package the accepted rules into a reusable Skill reference.

## Capstone C — Product visual campaign

Using authorised product facts and references:

1. build consumer map;
2. plan five head images and ten detail screens;
3. generate two direction samples;
4. review and revise plan;
5. generate independent finals;
6. validate product, text, claims and set diversity;
7. deliver contact sheets and QA.

## Capstone D — Management dashboard

Using an authorised dataset:

1. preserve and hash source;
2. build dictionary and quality profile;
3. clean with log;
4. define KPIs;
5. analyse time, region, channel, category and salesperson;
6. investigate three changes or exceptions;
7. build dashboard;
8. reconcile totals;
9. propose decisions and risks.
