## 四层比较

| 类型 | 特性 | Agent 适配 |
|---|---|---|
| GUI | 为人直接操作；画面改版会破坏流程 | 慢、昂贵、脆弱 |
| CLI | 命令清楚、速度快、可重复 | 高 |
| API | 封装业务能力、可批量及系统整合 | 高 |
| MCP | 让 Agent 发现并调用工具的协议层 | 高，但要治理工具及权限 |

## 教学流程

| 时间 | 主题 | 重点 |
|---|---|---|
| 00:00–04:00 | GUI 反例 | 录屏、操作网页及按钮会慢、烧 Token 并容易出错。 |
| 04:00–08:00 | MCP | 协议连接工具与 Agent；正名 MCP，不是 Raw 的 NCP。 |
| 08:00–12:00 | CLI／API | 可用 Codex 建立可重用命令及脚本，下一次成本更低。 |
| 12:00–15:44 | 工具选择 | 有 CLI／API 时不应默认 GUI；同时注意身份、Token 及参数。 |

## 练习

选一个每日使用的 GUI，查找它是否已有 CLI、API 或 MCP；画出由自然语言到工具执行的路径及权限。
