# 下午 02｜企业级模型选择与 Superpowers

## 教学主线

1. 企业／科研任务不应只用「看起来专业」的模型名称判断。
2. 模型选择同时看智能、价格、Token、速度及任务适配。
3. Agent 介面差异来自模型、Skill、MCP 及工作流整合。
4. Superpowers 用来先澄清、规划、审查，再实作。

## 教学流程

| 时间 | 主题 | 重点 |
|---|---|---|
| 00:00–06:00 | 模型与企业应用 | 强模型可降低反工率；成本要按完成结果计算。 |
| 06:00–12:00 | 模型／Agent 比较 | 同一工具名不代表相同模型、Skill 及 MCP 能力。 |
| 12:00–18:00 | Superpowers | 透过对话校准需求及计划，避免未想清楚便开工。 |
| 18:00–20:03 | 安装及调用 | Skill 可单独调用，也可为完整专案提供流程。 |

## 验收问题

- 是否在同一真实任务比较候选？
- 是否包含修改时间及失败成本？
- 是否知道底层模型、工具及权限？
- 是否有明确停止／验收条件？
