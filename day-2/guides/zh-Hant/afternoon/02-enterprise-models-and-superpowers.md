# 下午 02｜企業級模型選擇與 Superpowers

## 教學主線

1. 企業／科研任務不應只用「看起來專業」的模型名稱判斷。
2. 模型選擇同時看智能、價格、Token、速度及任務適配。
3. Agent 介面差異來自模型、Skill、MCP 及工作流整合。
4. Superpowers 用來先澄清、規劃、審查，再實作。

## 教學流程

| 時間 | 主題 | 重點 |
|---|---|---|
| 00:00–06:00 | 模型與企業應用 | 強模型可降低反工率；成本要按完成結果計算。 |
| 06:00–12:00 | 模型／Agent 比較 | 同一工具名不代表相同模型、Skill 及 MCP 能力。 |
| 12:00–18:00 | Superpowers | 透過對話校準需求及計劃，避免未想清楚便開工。 |
| 18:00–20:03 | 安裝及調用 | Skill 可單獨調用，也可為完整專案提供流程。 |

## 驗收問題

- 是否在同一真實任務比較候選？
- 是否包含修改時間及失敗成本？
- 是否知道底層模型、工具及權限？
- 是否有明確停止／驗收條件？
