## 四層比較

| 類型 | 特性 | Agent 適配 |
|---|---|---|
| GUI | 為人直接操作；畫面改版會破壞流程 | 慢、昂貴、脆弱 |
| CLI | 命令清楚、速度快、可重複 | 高 |
| API | 封裝業務能力、可批量及系統整合 | 高 |
| MCP | 讓 Agent 發現並調用工具的協議層 | 高，但要治理工具及權限 |

## 教學流程

| 時間 | 主題 | 重點 |
|---|---|---|
| 00:00–04:00 | GUI 反例 | 錄屏、操作網頁及按鈕會慢、燒 Token 並容易出錯。 |
| 04:00–08:00 | MCP | 協議連接工具與 Agent；正名 MCP，不是 Raw 的 NCP。 |
| 08:00–12:00 | CLI／API | 可用 Codex 建立可重用命令及腳本，下一次成本更低。 |
| 12:00–15:44 | 工具選擇 | 有 CLI／API 時不應默認 GUI；同時注意身份、Token 及參數。 |

## 練習

選一個每日使用的 GUI，查找它是否已有 CLI、API 或 MCP；畫出由自然語言到工具執行的路徑及權限。
