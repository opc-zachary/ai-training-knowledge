# 上午 04｜企業自動化演進與 FDE 落地

- 對應知識：K02、K07、K10；FDE 前置

## 學習目標

- 分辨 Prompt 模板、無代碼工作流、Agent／Skill／工作台三個自動化階段。
- 理解 FDE 的工程、業務及現場責任。
- 用低風險、高頻小場景建立企業 AI 信心。

## 教學流程

| 時間 | 主題 | 重點 |
|---|---|---|
| 00:00–04:00 | 自動化演進 | Prompt 模板 → 工作流平台 → Agent／本地工作台。 |
| 04:00–06:00 | 反面教材 | 節點少不代表簡單；接口、帳號及參數令非技術團隊難以維護。 |
| 06:00–08:00 | 企業入口 | 把資料、數據及腳本放入 Skill／看板，員工使用已設計入口。 |
| 08:00–10:00 | FDE 定義 | 工程師深入現場，連接 AI、企業邊界及實際流程。 |
| 10:00–12:00 | 試點場景 | 選高頻、較簡單、可見成果的小團隊，不先動核心業務。 |
| 12:00–15:12 | 陪伴式交付 | 認知升級、試點、上線、交接、復用及持續更新。 |

## FDE 接受標準

- 有工程交付能力。
- 理解 AI 與企業限制。
- 坐在業務旁觀察真實工作。
- 不破壞原流程地建立改造。
- 對採用及結果負責，而非只交軟件。
