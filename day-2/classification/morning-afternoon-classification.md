### 教學段落

| 時間 | 分類 | 知識點 |
|---|---|---|
| 00:00–02:00 | Context Window | 模型窗口有限，自壓縮會損失細節；複雜任務要拆分及重置上下文。 |
| 02:00–06:00 | 表達格式與排錯 | 結構化格式、圖像／影片提示詞；按目標、流程、格式及背景不足對症修正。 |
| 06:00–10:00 | Skill 定義 | Skill 是含 `SKILL.md` 及參考資源的文件夾，能保存偏好、流程及業務方法。 |
| 10:00–14:00 | 尋找 Skill | 以 GitHub 名稱、Star、下載量及實際需求判斷，而不是只等博主提供連結。 |
| 14:00–20:00 | Find Skill 實操 | 在 Skill Hub 安裝 Find Skill，用自然語言搜尋、排名及安裝候選。 |
| 20:00–24:00 | 由工作生成 Skill | 先跑通一個真實流程，確認結果好用，再要求 Agent 把已完成的方法封裝。 |
| 24:00–27:43 | Skill Creator 實操 | 把小生意分析流程交給 Skill Creator；最難部分是想清楚方法，不是按鈕。 |

### 分類重點

- Skill 不等於一段長提示詞；它可以包含規則、參考、資料及工具。
- 網上找到的 Skill 只代表候選，仍要測試、改造及確認是否符合自己的業務。
- 新安裝 Skill 未出現時，屬環境重新載入問題，不代表 Skill 本身無效。
