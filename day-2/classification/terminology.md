# 第二天專有名詞正名

| Raw／常見誤辨 | 正名 | 用途 |
|---|---|---|
| NCP | MCP | Agent 與工具協議層 |
| Hudders／HUNNUS／Hardless | Harness | Agent 的規則、工具、證據、回退及學習環境 |
| GetHub／GitAO／T-Hot／HIP HOP | GitHub | 開源程式、Skill 及知識載體 |
| Agent Beach | Agent Reach | 搜索文章、工具、Skill、Repo |
| SQ／SKU（本課語境） | Skill | 可重用工作方法 |
| Lobardy／Wobardi／握把你 | WorkBuddy | Agent 工作介面 |
| SuperPower／Supfer Power | Superpowers | 需求澄清、計劃、審查及實作流程 |
| 提字詞／提升詞 | 提示詞（Prompt） | 指令及背景 |
| LongChain | LangChain | LLM 應用框架 |
| LANDGRAPH | LangGraph | 圖狀 Agent 工作流 |
| Trading Agent | TradingAgents | Multi-Agent 投資研究案例 |
| 或PC | OPC | One Person Company |

## 課程關係

- Prompt：一次任務的指令與背景。
- Skill：可重用的方法、規則及參考。
- Harness：令 Agent 穩定工作的完整環境。
- Multi-Agent：有可拆證據與角色時使用的協作架構。
- FDE：深入企業現場完成 AI 落地及交付。
- OPC：用 AI 放大個人並快速驗證產品。
- Agent Boss：選問題、分角色、設權限及做驗收的人。
