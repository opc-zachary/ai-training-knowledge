# 学习路线 02｜内容／市场营运

目标：把行业研究、内容生产、平台数据及复盘连成可持续改善的工作台。

## 建议顺序

| 阶段 | 必读知识点 | 必做工作流 | 完成证据 |
|---|---|---|---|
| 1. 行业研究 | `LH-PE-002` 至 `LH-PE-008` | `LH-WF-01`、`LH-WF-02` | Prompt v02 及第二案例 |
| 2. Prompt 排错 | `LH-CTX-005`、`LH-CTX-006`、`LH-QA-004` | `LH-WF-03`、`LH-WF-05` | 一份新旧版本对照 |
| 3. Skill 沉淀 | `LH-SKL-001`、`LH-SKL-006`、`LH-SKL-008` | `LH-WF-07`、`LH-WF-08` | 内容流程 Skill 规格 |
| 4. 工作台 | `LH-WB-001` 至 `LH-WB-004` | `LH-WF-09` | 四周 MVP 画布 |
| 5. 数据闭环 | `LH-WB-005` 至 `LH-WB-007`、`LH-QA-006`、`LH-QA-007` | `LH-WF-10` | 月度复盘及下月测试 |

## 必做练习

1. 为一个真实行业建立研究 Prompt，加入三条从业者判断。
2. 选两个内容案例进行隔离测试。
3. 把内容状态缩至 Idea、Draft、Review、Ready。
4. 用互动和点击建立内容象限。
5. 为一篇双高及一篇双低内容提出可验证原因。

## 营运检查问题

- 情报来源进入工作台后会触发什么动作？
- 哪项工作仍在手动重复搬运？
- 总量上升是否只是因为发布量增加？
- 原因是数据事实还是尚待测试的假设？
- 哪条学习有足够证据升级成共用规则？

## 推荐教学

- `LH-TF-01` Prompt Engineering 与行业方法。
- `LH-TF-03` Skill 架构与个人 AI 工作台。

## 能力出口

完成者应能运行一条由研究到数据复盘的内容链，并每月以证据更新下一轮规则。
