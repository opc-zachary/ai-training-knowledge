# 學習路線 02｜內容／市場營運

目標：把行業研究、內容生產、平台數據及復盤連成可持續改善的工作台。

## 建議順序

| 階段 | 必讀知識點 | 必做工作流 | 完成證據 |
|---|---|---|---|
| 1. 行業研究 | `LH-PE-002` 至 `LH-PE-008` | `LH-WF-01`、`LH-WF-02` | Prompt v02 及第二案例 |
| 2. Prompt 排錯 | `LH-CTX-005`、`LH-CTX-006`、`LH-QA-004` | `LH-WF-03`、`LH-WF-05` | 一份新舊版本對照 |
| 3. Skill 沉澱 | `LH-SKL-001`、`LH-SKL-006`、`LH-SKL-008` | `LH-WF-07`、`LH-WF-08` | 內容流程 Skill 規格 |
| 4. 工作台 | `LH-WB-001` 至 `LH-WB-004` | `LH-WF-09` | 四週 MVP 畫布 |
| 5. 數據閉環 | `LH-WB-005` 至 `LH-WB-007`、`LH-QA-006`、`LH-QA-007` | `LH-WF-10` | 月度復盤及下月測試 |

## 必做練習

1. 為一個真實行業建立研究 Prompt，加入三條從業者判斷。
2. 選兩個內容案例進行隔離測試。
3. 把內容狀態縮至 Idea、Draft、Review、Ready。
4. 用互動和點擊建立內容象限。
5. 為一篇雙高及一篇雙低內容提出可驗證原因。

## 營運檢查問題

- 情報來源進入工作台後會觸發甚麼動作？
- 哪項工作仍在手動重複搬運？
- 總量上升是否只是因為發佈量增加？
- 原因是數據事實還是尚待測試的假設？
- 哪條學習有足夠證據升級成共用規則？

## 推薦教學

- `LH-TF-01` Prompt Engineering 與行業方法。
- `LH-TF-03` Skill 架構與個人 AI 工作台。

## 能力出口

完成者應能運行一條由研究到數據復盤的內容鏈，並每月以證據更新下一輪規則。
