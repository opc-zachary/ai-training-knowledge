# 教学模组 01｜Prompt Engineering 与行业方法

建议时长：75 分钟

## 对象与先备知识

- 对象：管理者、研究、策略、市场及需要重复使用 AI 的业务人员。
- 先备：曾使用聊天式 AI 完成至少一项工作；不要求程式背景。

## 学习成果

学员完成后能够：

1. 解释固定 Prompt 模板与行业方法的差别。
2. 用六个任务变量建立研究 Brief。
3. 把 AI 广度和人类专业判断合并。
4. 在干净窗口完成第二案例测试。

## 分钟级流程

| 时间 | 教学活动 | 讲师提示 | 学员产出 |
|---|---|---|---|
| 00–08 | 开场案例 | 展示同一通用 Prompt 在两个行业失准的例子 | 写出失准原因 |
| 08–18 | Prompt 演进 | 由固定框架讲到结构及行业化 | 三阶段笔记 |
| 18–30 | 六个任务变量 | 逐栏追问目标、对象、输入、输出、标准、边界 | 研究 Brief |
| 30–42 | 人机分工示范 | AI 先展开维度，讲师再加入行业权重 | 维度表 |
| 42–55 | 小组实作 | 每组选一个熟悉行业，补三条专业判断 | Prompt v01 |
| 55–65 | 隔离测试 | 换新窗口及第二细分类 | 测试差距 |
| 65–72 | 复盘版本 | 一次只改一个主要缺口 | Prompt v02 |
| 72–75 | Exit Ticket | 问「哪项内容不能交给 AI 自己猜？」 | 一句答案 |

## 讲师示范

1. 先说明要为谁做哪项决策，不立即要求完整报告。
2. 让 AI 提出通用行业研究维度。
3. 以政策对房地产、渠道对快消的重要性示范权重差异。
4. 生成 Prompt 后换窗口执行，公开指出隐藏 Context 缺口。

## 学员练习

每组选一个自己熟悉的行业：

1. 完成六栏 Brief。
2. 列出三条从业者判断。
3. 产出 Prompt v01。
4. 在第二细分类测试。
5. 只修改一个主要问题形成 v02。

## 检查问题

- 报告完成后，接收者要做什么决定？
- 哪三项是模型可能不知道的现场判断？
- 第二案例失败，代表通用骨架错还是行业层不足？
- 哪一项证据证明 v02 比 v01 更好？

## 课后作业

在七日内用同一 Prompt 完成两个真实案例，提交输入、输出、差距及版本更新。

## 评分量规

| 维度 | 未通过 | 基本通过 | 熟练 |
|---|---|---|---|
| 任务定义 | 只有题目 | 六栏大致完整 | 六栏能支援决策 |
| 行业判断 | 完全由 AI 提供 | 有一至两条人类判断 | 三条以上且改变优先级 |
| 测试 | 只跑原案例 | 有第二案例 | 第二及边界案例均有记录 |
| 版本 | 覆盖原 Prompt | 有 v01／v02 | 差异、原因及结果可追溯 |

通过标准：四个维度全部达到「基本通过」，并提交第二案例测试。

## 所需材料

- `LH-WF-01` 行业研究 Prompt 共创流程。
- `LH-WF-02` 隔离测试流程。
- 行业研究 Prompt 设计表及隔离测试记录。

## 证据边界

知识骨架来自老洪影片；课时设计、量规及分组方式是为团队授课而整理的教学设计。
