# 教學模組 01｜Prompt Engineering 與行業方法

建議時長：75 分鐘

## 對象與先備知識

- 對象：管理者、研究、策略、市場及需要重複使用 AI 的業務人員。
- 先備：曾使用聊天式 AI 完成至少一項工作；不要求程式背景。

## 學習成果

學員完成後能夠：

1. 解釋固定 Prompt 模板與行業方法的差別。
2. 用六個任務變量建立研究 Brief。
3. 把 AI 廣度和人類專業判斷合併。
4. 在乾淨窗口完成第二案例測試。

## 分鐘級流程

| 時間 | 教學活動 | 講師提示 | 學員產出 |
|---|---|---|---|
| 00–08 | 開場案例 | 展示同一通用 Prompt 在兩個行業失準的例子 | 寫出失準原因 |
| 08–18 | Prompt 演進 | 由固定框架講到結構及行業化 | 三階段筆記 |
| 18–30 | 六個任務變量 | 逐欄追問目標、對象、輸入、輸出、標準、邊界 | 研究 Brief |
| 30–42 | 人機分工示範 | AI 先展開維度，講師再加入行業權重 | 維度表 |
| 42–55 | 小組實作 | 每組選一個熟悉行業，補三條專業判斷 | Prompt v01 |
| 55–65 | 隔離測試 | 換新窗口及第二細分類 | 測試差距 |
| 65–72 | 復盤版本 | 一次只改一個主要缺口 | Prompt v02 |
| 72–75 | Exit Ticket | 問「哪項內容不能交給 AI 自己猜？」 | 一句答案 |

## 講師示範

1. 先說明要為誰做哪項決策，不立即要求完整報告。
2. 讓 AI 提出通用行業研究維度。
3. 以政策對房地產、渠道對快消的重要性示範權重差異。
4. 生成 Prompt 後換窗口執行，公開指出隱藏 Context 缺口。

## 學員練習

每組選一個自己熟悉的行業：

1. 完成六欄 Brief。
2. 列出三條從業者判斷。
3. 產出 Prompt v01。
4. 在第二細分類測試。
5. 只修改一個主要問題形成 v02。

## 檢查問題

- 報告完成後，接收者要做甚麼決定？
- 哪三項是模型可能不知道的現場判斷？
- 第二案例失敗，代表通用骨架錯還是行業層不足？
- 哪一項證據證明 v02 比 v01 更好？

## 課後作業

在七日內用同一 Prompt 完成兩個真實案例，提交輸入、輸出、差距及版本更新。

## 評分量規

| 維度 | 未通過 | 基本通過 | 熟練 |
|---|---|---|---|
| 任務定義 | 只有題目 | 六欄大致完整 | 六欄能支援決策 |
| 行業判斷 | 完全由 AI 提供 | 有一至兩條人類判斷 | 三條以上且改變優先級 |
| 測試 | 只跑原案例 | 有第二案例 | 第二及邊界案例均有記錄 |
| 版本 | 覆蓋原 Prompt | 有 v01／v02 | 差異、原因及結果可追溯 |

通過標準：四個維度全部達到「基本通過」，並提交第二案例測試。

## 所需材料

- `LH-WF-01` 行業研究 Prompt 共創流程。
- `LH-WF-02` 隔離測試流程。
- 行業研究 Prompt 設計表及隔離測試記錄。
