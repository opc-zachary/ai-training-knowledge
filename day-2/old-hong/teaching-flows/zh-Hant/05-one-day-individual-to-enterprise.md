# 一日課程｜由個人方法到企業落地

有效教學時間：360 分鐘；另設午膳及兩次短休息。

## 對象與先備知識

- 對象：企業管理者、部門骨幹、內容營運、AI 推動者及解決方案團隊。
- 先備：每組帶來一項重複工作、一個失敗 Prompt 和三個企業候選場景。

## 學習成果

1. 建立並隔離測試一個行業 Prompt。
2. 完成一個可重用 Skill 的頂層規格。
3. 畫出個人或部門 AI 工作台 MVP。
4. 選擇一個 FDE 試點並建立交付章程。

## 分鐘級流程

| 時間 | 模組 | 核心活動 | 階段產出 |
|---|---|---|---|
| 00–20 | 開場與基線 | 個人工作、AI 失敗及企業場景盤點 | 現況基線 |
| 20–75 | Prompt 方法 | 六欄 Brief、人機共創、行業權重 | Prompt v01 |
| 75–95 | 隔離測試 | 新窗口及第二案例 | 測試差距 |
| 95–105 | 休息 | — | — |
| 105–145 | Context 與排錯 | 四層診斷及最小修訂 | Prompt v02 |
| 145–190 | Skill 設計 | 成功案例、隱性判斷、路由與驗收 | Skill 規格 |
| 190–250 | 午膳 | — | — |
| 250–295 | 工作台 MVP | 情報、生產、數據、復盤 | MVP 畫布 |
| 295–330 | 數據回流 | 指標、象限、原因假設及規則 | 復盤表 |
| 330–340 | 休息 | — | — |
| 340–385 | 自動化選型 | 模板、工作流、Skill、Agent 比較 | 選型表 |
| 385–430 | FDE 試點 | 場景評分、邊界、四階段交付 | 試點章程 |
| 430–450 | Capstone 發表 | 每組講述由個人方法到企業試點 | 完整方案 |

## 模組轉場

- Prompt → Skill：一次成功要變成可重用方法，必須補案例、例外及驗收。
- Skill → 工作台：單一能力要產生持續價值，必須接入上下游及結果回流。
- 工作台 → 企業：個人能用不代表全員會用，企業需要入口、責任和維護。
- 企業 → FDE：工具不能自行理解現場，必須有人連接工程和業務。

## 講師示範

使用同一個「每月行業及內容洞察」案例貫穿全日：先做 Prompt，再封裝 Skill、連入工作台，最後設計小團隊試點。

## 學員練習

Capstone 必須包含：

1. 六欄問題定義。
2. Prompt v01／v02 及第二案例差距。
3. Skill 觸發、輸入、輸出、規則和驗收。
4. 工作台四層及一個數據回流。
5. 自動化選型理由。
6. FDE 試點基線、邊界、期限、回退及四類驗收。

## 檢查問題

- 這項工作為何值得重複自動化？
- 哪些知識來自業務專家而不是模型？
- 非作者能否在乾淨 Context 完成？
- 個人工作台的結果如何改變下一輪規則？
- 為甚麼選這個試點而不是更大的核心流程？

## 課後作業

兩週內完成 Prompt／Skill 試用；四週內完成工作台或 FDE 小試點的第一輪回讀。

## 評分量規

| 維度 | 權重 | 通過證據 |
|---|---:|---|
| 問題及行業判斷 | 20% | 六欄完整、三條專業判斷 |
| Prompt 及測試 | 20% | 第二案例、新舊差距可追溯 |
| Skill 架構 | 20% | 路由、規則、資源、驗收清楚 |
| 工作台閉環 | 20% | 資訊到復盤完整、有一項量度 |
| 企業試點 | 20% | 場景評分、回退及四類驗收 |

通過標準：總分 70 分以上，且企業試點維度不得低於該項 60%。

## 所需材料

- 九條指定工作流。
- 八份可複製模板。
- 小組案例、計時器及成果發表表。

## 證據邊界

一日結構是把老洪四段內容轉成連續能力路線的教學設計，不代表原課堂以相同課時或活動授課。
