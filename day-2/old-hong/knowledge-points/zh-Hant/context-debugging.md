# 老洪知識點｜Context 與 Prompt 排錯

本章整理長任務的資訊管理，以及輸出偏差時的診斷順序。

### LH-CTX-001｜Context Window 是有限工作記憶

- 一句話：同一窗口承載的歷史越多，可供當前任務使用的有效空間便越少。
- 課堂原意：老洪指出長對話會令早期細節遺失，複雜任務需要拆分或開新窗口。
- 整理與應用：Context 應視為任務資源；不是資料放得越多越好，而是保留與當前判斷有關的內容。
- 使用時機：對話很長、要求很多、模型開始忘記早期約束。
- 不適用：短小且輸入明確的單輪任務。
- 下一步：列出當前任務真正需要保留的目標、來源、規則和狀態。
- 關聯流程：`LH-WF-04`
- Evidence：`DJI_20260830102734_0001_D|00:22:00-00:27:00|Cleaned_Review`

### LH-CTX-002｜自動壓縮可能犧牲細節

- 一句話：系統為延續長對話而壓縮歷史時，細節、例外和先後關係可能被弱化。
- 課堂原意：第二段開首延續 Context Window，說明過長內容會導致資訊損失。
- 整理與應用：重要限制要寫入明確的任務摘要或來源文件，不可只依賴對話記憶。
- 使用時機：長期項目、跨日工作、多個文件或多人規則共同存在。
- 不適用：資料可隨時由單一權威文件重新載入。
- 下一步：把不可遺失的五項規則整理成「重新開始也能使用」的 Context Brief。
- 關聯流程：`LH-WF-04`
- Evidence：`DJI_20260830105517_0002_D|00:00:00-00:02:00|Cleaned_Review`

### LH-CTX-003｜新窗口是隔離實驗環境

- 一句話：測試 Prompt 時要在乾淨窗口執行，避免舊對話暗中提供答案。
- 課堂原意：老洪示範把第一版提示詞放到新任務，測試它是否單獨成立。
- 整理與應用：舊 Context 可協助設計 Prompt，但驗收必須在沒有隱藏背景的環境進行。
- 使用時機：準備交付 Prompt、Skill 或標準流程給其他人。
- 不適用：刻意需要延續個人偏好和項目歷史的同一工作線。
- 下一步：把 Prompt 複製到新窗口，只提供正式輸入，記錄是否仍能產出合格結果。
- 關聯流程：`LH-WF-02`
- Evidence：`DJI_20260830102734_0001_D|00:18:00-00:22:00|Cleaned_Review`

### LH-CTX-004｜複雜任務要按成果切分

- 一句話：切分任務的單位應是可驗收成果，而不是任意把長文字分成幾段。
- 課堂原意：課堂建議複雜內容分塊處理，避免單一 Context 承載全部工作。
- 整理與應用：每一段要有輸入、產出、完成條件及交接摘要，下一段才能安全延續。
- 使用時機：研究、內容生產、資料分析或跨多階段的 Agent 任務。
- 不適用：步驟高度耦合，拆開後會失去必要的即時狀態。
- 下一步：把一個大任務改寫為三個各自可驗收的交付物。
- 關聯流程：`LH-WF-04`
- Evidence：`DJI_20260830102734_0001_D|00:24:00-00:27:42|Cleaned_Review`

### LH-CTX-005｜結構化格式減少理解歧義

- 一句話：標題、欄位、清單和輸出格式能把自然語言要求轉成較穩定的操作規格。
- 課堂原意：老洪在 Prompt 格式與排錯部分強調結構化表達對控制輸出的作用。
- 整理與應用：結構不是為了讓 Prompt 看起來複雜，而是讓每項要求可以逐一檢查。
- 使用時機：要求包含多個對象、步驟、限制或格式。
- 不適用：簡短探索對話，過早固定格式會限制發現空間。
- 下一步：把一段散文式要求改成「目標／資料／步驟／輸出／驗收」。
- 關聯流程：`LH-WF-05`
- Evidence：`DJI_20260830105517_0002_D|00:02:00-00:06:00|Cleaned_Review`

### LH-CTX-006｜Prompt 四層排錯

- 一句話：答非所問時，依序檢查目標、流程、格式及背景資料，不要只叫模型「再做好一點」。
- 課堂原意：課堂把 Prompt 問題拆成目標、流程、格式、背景四類。
- 整理與應用：四層對應四種修復方式：重定義成果、補方法、明確結構、補充來源。
- 使用時機：結果不合格，但不知道問題來自哪裡。
- 不適用：工具故障、權限不足或輸入檔案損壞等非 Prompt 問題。
- 下一步：只選一層做最小修改，再重跑同一測試案例。
- 關聯流程：`LH-WF-05`
- Evidence：`DJI_20260830105517_0002_D|00:02:30-00:06:00|Cleaned_Review`

### LH-CTX-007｜重置 Context 前先留下交接摘要

- 一句話：開新窗口不是把一切忘掉，而是只帶走已確認的目標、資料、決定和未完成項。
- 課堂原意：Context 管理的目的，是避免舊內容污染，同時保留任務需要的背景。
- 整理與應用：交接摘要應區分事實、決定、假設、限制及下一步，避免把推測變成真相。
- 使用時機：任務跨窗口、跨人或跨 Agent 延續。
- 不適用：新任務與舊任務完全無關，沒有任何狀態需要保留。
- 下一步：用五個欄位製作一頁 Handoff，再在新窗口以它作唯一歷史輸入。
- 關聯流程：`LH-WF-04`
- Evidence：`DJI_20260830105517_0002_D|00:00:00-00:02:00|Cleaned_Review`

### LH-CTX-008｜先分辨 Prompt 問題與系統問題

- 一句話：輸出失敗不一定是 Prompt 寫得差，也可能是資料、工具、能力或 Context 不足。
- 課堂原意：老洪把排錯與 Skill、資料及工具結合，提醒學員不要把所有失敗都歸因於一句指令。
- 整理與應用：先定位失敗層，才能選擇重寫 Prompt、補資料、換工具或拆任務。
- 使用時機：同一 Prompt 有時成功、有時失敗，或模型沒有實際執行能力。
- 不適用：已明確看到要求本身互相矛盾，應先修正規格。
- 下一步：為一次失敗標記 `Prompt／Context／Input／Tool／Rule` 其中一個主要原因。
- 關聯流程：`LH-WF-05`、`LH-WF-07`
- Evidence：`DJI_20260830105517_0002_D|00:04:00-00:08:00|Cleaned_Review`
