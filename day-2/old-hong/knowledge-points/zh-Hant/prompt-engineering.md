# 老洪知識點｜Prompt Engineering

本章把提示詞由「句子技巧」還原為可測試的工作方法。整理內容不是逐字引用；證據欄指向老洪課堂的清理逐字稿。

### LH-PE-001｜好 Prompt 是跑出來的

- 一句話：提示詞的品質要由實際執行結果證明，而不是由文字看起來是否專業決定。
- 課堂原意：老洪把好提示詞描述為先執行、再復盤、再修改，通常要來回數輪才貼近日常業務。
- 整理與應用：保存每一版輸入、輸出與差距，逐項修訂，才能形成穩定資產。
- 使用時機：同類任務會重複出現，且輸出品質值得持續改善。
- 不適用：一次性、低風險、沒有重用價值的簡單問答。
- 下一步：選一項每週工作，完成第一輪執行並記錄三個不符合預期之處。
- 關聯流程：`LH-WF-01`、`LH-WF-03`

### LH-PE-002｜提示詞已由固定框架走向行業方法

- 一句話：Prompt Engineering 的重點已由套模板，轉向結構化思考及行業知識。
- 課堂原意：老洪回顧固定框架、把 Prompt 視為溝通編程語言，以及按不同行業深化方法的演進。
- 整理與應用：框架只提供起點；真正差異來自業務變量、判斷標準及專業限制。
- 使用時機：團隊仍在收藏 Prompt 模板，但輸出與實務工作脫節。
- 不適用：已有成熟工作方法，只需把既有規格交給 Agent 執行的情況。
- 下一步：在現有模板標出哪些欄位是通用結構、哪些必須由行業專家補充。
- 關聯流程：`LH-WF-01`

### LH-PE-003｜先定義六個任務變量

- 一句話：清楚的目標、對象、輸入、輸出、標準及邊界，是 Prompt 可控的前提。
- 課堂原意：老洪在說明好提示詞來源時，先要求學員想清楚要解決甚麼任務及其中關鍵要素。
- 整理與應用：六個變量可直接成為任務 Brief；缺少任何一項，都容易令 Agent 自行猜測。
- 使用時機：輸出看似完整，但與決策者真正需要的內容不同。
- 不適用：純探索對話，當下目的就是讓 AI 協助發現問題。
- 下一步：用六個欄位重寫一項模糊指令，並標示仍未知的假設。
- 關聯流程：`LH-WF-01`、`LH-WF-05`
- Evidence：`DJI_20260830102734_0001_D|00:08:00-00:11:00|Cleaned_Review`

### LH-PE-004｜先與 AI 共創問題，再要求它寫 Prompt

- 一句話：不要一開始便要求最終提示詞，先讓 AI 與你共同補全分析維度。
- 課堂原意：行業研究示範先描述要交付給老闆的報告，再詢問完整分析應包含哪些層面。
- 整理與應用：探索對話和正式執行應分開；前者擴展問題，後者固定可重複規格。
- 使用時機：你知道業務目的，但尚未掌握完整研究框架。
- 不適用：法規、合約或高風險工作，不可把未知要求完全交由模型推斷。
- 下一步：先問 AI「這個任務還缺哪些決策維度」，不要立即要求最終成品。
- 關聯流程：`LH-WF-01`
- Evidence：`DJI_20260830102734_0001_D|00:10:00-00:13:00|Cleaned_Review`

### LH-PE-005｜AI 補廣度，人補行業判斷

- 一句話：AI 擅長展開可能性，從業者負責加入真實業務判斷與優先次序。
- 課堂原意：老洪以房地產政策、快消平台數據等例子，說明行業人必須補入模型不知道的實務重點。
- 整理與應用：最有效的人機分工不是讓 AI 取代專家，而是由 AI 建候選框架、專家修正權重和缺口。
- 使用時機：研究、策略、方案及任何需要行業語境的工作。
- 不適用：使用者本身沒有相關知識，亦沒有可靠來源可驗證的高風險結論。
- 下一步：加入三條「只有實際從業者才知道」的判斷，再讓 AI 重組框架。
- 關聯流程：`LH-WF-01`
- Evidence：`DJI_20260830102734_0001_D|00:13:00-00:18:00|Cleaned_Review`

### LH-PE-006｜同一研究框架必須按行業改變權重

- 一句話：通用分析維度不能平均套用，行業差異會改變資料來源和章節優先級。
- 課堂原意：房地產需要把政策及監管提到高位；快消則更重視渠道、銷量和消費者資料。
- 整理與應用：保留通用骨架，但為每個行業設定必查來源、核心指標、風險及決策順序。
- 使用時機：把同一研究 Prompt 擴展至不同產業或細分類。
- 不適用：兩個任務只共享表面名稱，實際決策目標完全不同。
- 下一步：建立「通用欄位／行業必填／可選欄位」三層研究表。
- 關聯流程：`LH-WF-01`、`LH-WF-02`

### LH-PE-007｜觀察 Agent 的執行過程

- 一句話：不要只等最終答案；觀察工具選擇及中間步驟，才能知道偏差在哪裡發生。
- 課堂原意：示範中 Agent 自行製作視覺內容，老洪指出應查看它正在做甚麼，必要時可打斷。
- 整理與應用：過程觀察可分辨「方向錯誤」和「成品表達不佳」，避免只在末端補救。
- 使用時機：任務時間長、會調用多個工具，或中途成本可能快速增加。
- 不適用：模型或平台不提供過程資訊，只能以輸入輸出驗證。
- 下一步：為下一個長任務記錄三項中途檢查點及停止條件。
- 關聯流程：`LH-WF-03`、`LH-WF-05`
- Evidence：`DJI_20260830102734_0001_D|00:12:00-00:16:00|Cleaned_Review`

### LH-PE-008｜用另一個細分類測試通用性

- 一句話：Prompt 在原案例成功，不等於已經可重用；必須換一個相近但不同的案例驗證。
- 課堂原意：老洪要求把整理後提示詞放到新任務，並以不同品類檢查是否仍能工作。
- 整理與應用：第一個案例負責建立方法，第二個案例負責揭露過度擬合和隱藏假設。
- 使用時機：準備把 Prompt 交給同事、封裝成 Skill 或納入自動化。
- 不適用：明確只服務單一固定個案，沒有重用需求。
- 下一步：選擇一個結構相似但資料不同的案例，對照兩次輸出差距。
- 關聯流程：`LH-WF-02`、`LH-WF-07`
- Evidence：`DJI_20260830102734_0001_D|00:18:00-00:22:00|Cleaned_Review`
