# 老洪知识点｜Prompt Engineering

本章把提示词由「句子技巧」还原为可测试的工作方法。整理内容不是逐字引用；证据栏指向老洪课堂的清理逐字稿。

### LH-PE-001｜好 Prompt 是跑出来的

- 一句话：提示词的品质要由实际执行结果证明，而不是由文字看起来是否专业决定。
- 课堂原意：老洪把好提示词描述为先执行、再复盘、再修改，通常要来回数轮才贴近日常业务。
- 整理与应用：保存每一版输入、输出与差距，逐项修订，才能形成稳定资产。
- 使用时机：同类任务会重复出现，且输出品质值得持续改善。
- 不适用：一次性、低风险、没有重用价值的简单问答。
- 下一步：选一项每周工作，完成第一轮执行并记录三个不符合预期之处。
- 关联流程：`LH-WF-01`、`LH-WF-03`

### LH-PE-002｜提示词已由固定框架走向行业方法

- 一句话：Prompt Engineering 的重点已由套模板，转向结构化思考及行业知识。
- 课堂原意：老洪回顾固定框架、把 Prompt 视为沟通编程语言，以及按不同行业深化方法的演进。
- 整理与应用：框架只提供起点；真正差异来自业务变量、判断标准及专业限制。
- 使用时机：团队仍在收藏 Prompt 模板，但输出与实务工作脱节。
- 不适用：已有成熟工作方法，只需把既有规格交给 Agent 执行的情况。
- 下一步：在现有模板标出哪些栏位是通用结构、哪些必须由行业专家补充。
- 关联流程：`LH-WF-01`

### LH-PE-003｜先定义六个任务变量

- 一句话：清楚的目标、对象、输入、输出、标准及边界，是 Prompt 可控的前提。
- 课堂原意：老洪在说明好提示词来源时，先要求学员想清楚要解决什么任务及其中关键要素。
- 整理与应用：六个变量可直接成为任务 Brief；缺少任何一项，都容易令 Agent 自行猜测。
- 使用时机：输出看似完整，但与决策者真正需要的内容不同。
- 不适用：纯探索对话，当下目的就是让 AI 协助发现问题。
- 下一步：用六个栏位重写一项模糊指令，并标示仍未知的假设。
- 关联流程：`LH-WF-01`、`LH-WF-05`
- Evidence：`DJI_20260830102734_0001_D|00:08:00-00:11:00|Cleaned_Review`

### LH-PE-004｜先与 AI 共创问题，再要求它写 Prompt

- 一句话：不要一开始便要求最终提示词，先让 AI 与你共同补全分析维度。
- 课堂原意：行业研究示范先描述要交付给老板的报告，再询问完整分析应包含哪些层面。
- 整理与应用：探索对话和正式执行应分开；前者扩展问题，后者固定可重复规格。
- 使用时机：你知道业务目的，但尚未掌握完整研究框架。
- 不适用：法规、合约或高风险工作，不可把未知要求完全交由模型推断。
- 下一步：先问 AI「这个任务还缺哪些决策维度」，不要立即要求最终成品。
- 关联流程：`LH-WF-01`

### LH-PE-005｜AI 补广度，人补行业判断

- 一句话：AI 擅长展开可能性，从业者负责加入真实业务判断与优先次序。
- 课堂原意：老洪以房地产政策、快消平台数据等例子，说明行业人必须补入模型不知道的实务重点。
- 整理与应用：最有效的人机分工不是让 AI 取代专家，而是由 AI 建候选框架、专家修正权重和缺口。
- 使用时机：研究、策略、方案及任何需要行业语境的工作。
- 不适用：使用者本身没有相关知识，亦没有可靠来源可验证的高风险结论。
- 下一步：加入三条「只有实际从业者才知道」的判断，再让 AI 重组框架。
- 关联流程：`LH-WF-01`

### LH-PE-006｜同一研究框架必须按行业改变权重

- 一句话：通用分析维度不能平均套用，行业差异会改变资料来源和章节优先级。
- 课堂原意：房地产需要把政策及监管提到高位；快消则更重视渠道、销量和消费者资料。
- 整理与应用：保留通用骨架，但为每个行业设定必查来源、核心指标、风险及决策顺序。
- 使用时机：把同一研究 Prompt 扩展至不同产业或细分类。
- 不适用：两个任务只共享表面名称，实际决策目标完全不同。
- 下一步：建立「通用栏位／行业必填／可选栏位」三层研究表。
- 关联流程：`LH-WF-01`、`LH-WF-02`
- Evidence：`DJI_20260830102734_0001_D|00:14:30-00:18:30|Cleaned_Review`

### LH-PE-007｜观察 Agent 的执行过程

- 一句话：不要只等最终答案；观察工具选择及中间步骤，才能知道偏差在哪里发生。
- 课堂原意：示范中 Agent 自行制作视觉内容，老洪指出应查看它正在做什么，必要时可打断。
- 整理与应用：过程观察可分辨「方向错误」和「成品表达不佳」，避免只在末端补救。
- 使用时机：任务时间长、会调用多个工具，或中途成本可能快速增加。
- 不适用：模型或平台不提供过程资讯，只能以输入输出验证。
- 下一步：为下一个长任务记录三项中途检查点及停止条件。
- 关联流程：`LH-WF-03`、`LH-WF-05`
- Evidence：`DJI_20260830102734_0001_D|00:12:00-00:16:00|Cleaned_Review`

### LH-PE-008｜用另一个细分类测试通用性

- 一句话：Prompt 在原案例成功，不等于已经可重用；必须换一个相近但不同的案例验证。
- 课堂原意：老洪要求把整理后提示词放到新任务，并以不同品类检查是否仍能工作。
- 整理与应用：第一个案例负责建立方法，第二个案例负责揭露过度拟合和隐藏假设。
- 使用时机：准备把 Prompt 交给同事、封装成 Skill 或纳入自动化。
- 不适用：明确只服务单一固定个案，没有重用需求。
- 下一步：选择一个结构相似但资料不同的案例，对照两次输出差距。
- 关联流程：`LH-WF-02`、`LH-WF-07`
- Evidence：`DJI_20260830102734_0001_D|00:18:00-00:22:00|Cleaned_Review`
