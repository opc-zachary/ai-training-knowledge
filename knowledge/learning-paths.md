# Learning Paths

## Founder or manager

1. K01 model/Agent framework.
2. K02 bounded operation.
3. K03 evidence-led research.
4. K09 management data.
5. K10 acceptance and readback.
6. Day-two workflow, Harness and Agent Boss reference.

Outcome: define goals, assign AI work and judge results without needing to operate every tool personally.

## Brand and marketing operator

1. K03 research.
2. K04 consumer/platform insight.
3. K05 author voice.
4. K06 image control.
5. K07 visual set.
6. K08 video.
7. K10 delivery QA.

Outcome: operate an evidence-led one-person marketing workflow.

## Content creator

1. K05 author voice.
2. K06 visual control.
3. K08 video.
4. K10 verification.

Outcome: produce recognisable content without generic AI language or disconnected visuals.

## Designer or e-commerce team

1. K01 model/tool choice.
2. K06 controlled image generation.
3. K07 e-commerce visual Skill.
4. K08 moving-image extension.
5. K10 output QA.

Outcome: convert visual direction into a scalable, coherent production system.

## Data or operations team

1. K02 workspace and permissions.
2. K09 data workflow.
3. K10 reconciliation and readback.
4. Day-two Harness and Agent Team reference.

Outcome: build repeatable analysis with explicit data quality and acceptance evidence.

## Four-week schedule

| Week | Focus | Output |
|---|---|---|
| 1 | K01–K03 | Agent brief and research report |
| 2 | K04–K05 | Insight map and author voice system |
| 3 | K06–K08 | Visual set plan and five-shot storyboard |
| 4 | K09–K10 | Reconciled dashboard and QA report |
