## Data workflow

```text
Raw file
→ schema inspection
→ quality profile
→ cleaning decisions
→ metric definitions
→ descriptive analysis
→ change and exception analysis
→ visualisation
→ reconciliation
→ decision and follow-up
```

## Minimum data-quality profile

| Check | Why it matters |
|---|---|
| Row count and date range | Establish scope |
| Unique key and duplicates | Prevent double counting |
| Missing values | Reveal incomplete records |
| Data types | Stop text/date/number confusion |
| Valid value ranges | Detect impossible quantities or margins |
| Category normalisation | Avoid split groups caused by spelling |
| Metric formula | Make totals reproducible |
| Reconciliation total | Compare output with the source system |

## Business questions by dimension

- Time: What changed month over month and is it seasonal?
- Region: Is growth broad or concentrated?
- Channel: Which channel produces revenue versus margin?
- Category: Which products drive growth, discount or returns?
- Salesperson: Who changed materially and in which product/region mix?
- Customer: Is growth new-customer acquisition or repeat purchase?

## Dashboard acceptance

- Every KPI has a definition.
- Filters do not change totals unexpectedly.
- Charts use the same cleaned dataset.
- Source row samples reconcile with aggregate values.
- Missing and excluded records are disclosed.
- The executive conclusion follows the data rather than decorative charts.
