## Purpose

This video moves from concepts to a desktop Agent interface. The important lesson is not where each button sits; it is how to create a task, define a workspace, manage permissions and connect reusable organisational capability.

## The six-part Agent workspace

| Part | Function | Control question |
|---|---|---|
| Task | One outcome to complete | What exactly is done? |
| Workspace | Files the Agent may use | What is inside and outside scope? |
| Project | Persistent context | Which client and business context apply? |
| Skill/expert | Reusable method | Has this method been tested on our case? |
| Knowledge | Stable reference facts | Is it current and authoritative? |
| Connector | External action surface | Which identity, object and permission are being used? |

## Safe operating pattern

1. Make a project-specific folder.
2. Copy only required working files into it.
3. Start with normal permission rather than unrestricted access.
4. State prohibited actions in the task.
5. Require versioned outputs.
6. Review the proposed result before external delivery.
7. Verify the destination after any write.

## Practical exercise

Build a one-page Agent task brief:

```text
Goal:
Workspace:
Inputs:
Expected files:
Required method or Skill:
What the Agent may not do:
Acceptance checks:
```

Run it only after each line has a concrete answer.
