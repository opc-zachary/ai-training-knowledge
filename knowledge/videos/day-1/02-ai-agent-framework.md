## Learning outcomes

After this video, the learner should be able to:

- explain the difference between a model, an application, a specialist tool and an Agent product;
- understand why business-led learning is more useful than following every AI announcement;
- distinguish dialogue products from goal-driven Agent workflows;
- choose a model and tool as two separate decisions;
- recognise that cost, quality, latency, language, media type and task style all affect model choice.

## Core mental model

```text
Business goal
  ↓
Agent product or workflow
  ├── model selection
  ├── tools and connectors
  ├── files and knowledge
  ├── permissions
  └── verification
  ↓
Deliverable or action
```

## Decision matrix

| Question | What to inspect |
|---|---|
| Is this a conversation or a multi-step job? | Dialogue app versus Agent workflow |
| Is the output text, image, audio, video, data or mixed? | Required capability family |
| Does style matter more than reasoning? | Test candidate models on the real brief |
| Will the Agent touch files or external systems? | Workspace, permissions and readback |
| Is a result expensive to regenerate? | Acceptance criteria before generation |
| Is the claim time-sensitive? | Source date and current verification |

## Common mistakes

- Asking “what is the best AI” without defining the task.
- Confusing an interface with its underlying model.
- Assuming the newest model is best for every writing voice.
- Judging video only by a highlight reel rather than usable yield and cost.
- Treating Agent autonomy as permission to operate without boundaries.

## Exercise

Choose one real task and write:

1. business goal;
2. required output;
3. dialogue, specialist tool or Agent;
4. required model capabilities;
5. tools and files;
6. risk boundary;
7. acceptance test.

If any item is missing, the task is not ready to delegate.
