# K07 — Reusable E-commerce Visual Skill

## Objective

Turn a product, facts and visual references into a coherent, reviewable set instead of disconnected image prompts.

## Planning sequence

1. Inspect product, reference and fact inputs.
2. Build consumer anxieties, outcomes, objections and proof map.
3. Define visual DNA and colour rules.
4. Assign five head-image roles.
5. Assign ten detail-screen roles.
6. Write one visual-proof statement per output.
7. Review the whole set before generation.
8. Generate independently but maintain set context.
9. Validate both each file and the set.

## Set roles

- Head image 1: click and core proposition.
- Head images 2–4: distinct proof of benefits.
- Head image 5: audience, scenario or objection.
- Detail screens: hero → situation/problem → benefits → detail/mechanism → trust → close.

## Acceptance

- Five head images use at least four distinct main visuals.
- Ten detail screens use at least seven distinct main visuals.
- The product is not forced into every screen.
- Adjacent screens do not repeat the same composition.
- All copy uses consumer language and supported claims.
- Set colour, type and light remain coherent.

## Failure signals

- ten vertical hero posters rather than a detail-page narrative;
- the same product pose repeated throughout;
- reference scene copied into every output;
- no approval of the set plan before expensive generation;
- one file repaired while set inconsistency remains.
