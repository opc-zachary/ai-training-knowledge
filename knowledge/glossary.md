# Glossary

| Term | Working definition in this course |
|---|---|
| Model | The underlying system that performs reasoning, language or media generation. |
| Interface | The app, website, CLI or API through which a model is used. |
| Tool | A callable capability such as file access, search, code execution or external API. |
| Agent | A system that receives a goal, plans steps, uses tools and advances work toward a deliverable. |
| Dialogue product | A product primarily returning answers turn by turn. |
| Specialist tool | A narrow product for one capability such as image or video generation. |
| Multimodal | Able to understand or generate more than one media type. |
| Token | A model-processing unit used for context and pricing; not equal to one word. |
| Context | Information available to the model during a task. |
| Prompt | Instruction and context supplied for one interaction or task. |
| Systematic prompt | A reusable instruction encoding goal, inputs, method, output and boundaries. |
| Skill | A packaged set of reusable instructions and references for a recurring task. |
| Workflow | Ordered human and Agent steps that turn inputs into a verified outcome. |
| Connector | A bridge allowing an Agent to read or write another system. |
| MCP | A protocol pattern for exposing tools and context to AI systems. |
| API | A programmatic interface between systems. |
| GUI | A graphical user interface. |
| CLI | A command-line interface. |
| Harness | The operating system around a model: tools, memory, rules, tests, feedback and runtime. |
| Agent Team | Multiple role-specific Agents collaborating on one objective. |
| Agent Boss | The human role that defines goal, team, standards, permissions and acceptance. |
| FDE | Forward Deployed Engineer; an embedded role connecting product capability to a real operating environment. |
| OPC | One Person Company in the deck's business context; a highly leveraged operator using AI systems. |
| Visual DNA | Transferable visual rules such as type, light, density, colour organisation and mood. |
| Picture-solo statement | What an image proves when all copy is hidden. |
| Head image | A marketplace listing image designed for click, proposition or proof. |
| Detail screen | One screen in a longer e-commerce detail-page narrative. |
| Reverse prompting | Analysing a reference into structured visual guidance. |
| Hallucination | Unsupported or fabricated model output presented as if true. |
| Reconciliation | Comparing derived results with source records or an independent total. |
| Readback | Reading the exact destination object after a write to prove what actually happened. |
| Usable yield | The proportion of generated output that survives quality review and is used. |
| Reference only | Available from a secondary structure such as a deck, not yet verified against the video evidence. |
