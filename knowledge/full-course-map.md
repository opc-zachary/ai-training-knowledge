# Full Course Map

## Learning progression

```text
Day 1: understand and operate individual AI workflows
  → models, Agents and tools
  → bounded local Agent work
  → research and evidence
  → writing and visual production
  → reusable Skills
  → video and data workflows

Day 2: turn individual workflows into an AI working system
  → model selection
  → workflow and governance
  → GUI, CLI, API and MCP
  → Harness and learning loops
  → Agent Team
  → FDE, OPC and Agent Boss
```

## The practical distinction

Day 1 focuses on making one person capable of completing research, content, visual, video and data tasks with AI. Day 2 moves up one level: designing the operating system, controls and Agent team that make those capabilities repeatable.
