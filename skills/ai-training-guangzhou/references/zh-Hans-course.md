|---|---|

## 回答结构

1. 指出模组及证据状态。
2. 解释核心概念。
3. 第一天提供影片 ID 及时间范围。
4. 给出实际工作流、输入及交付。
5. 列出常见失败及验收。
6. 提供一个练习或可填模板。
7. 说明与下一模组的关系。

## 第一天主线

```text
业务目标
→ Agent／模型／工具
→ 有边界工作空间
→ 研究与平台证据
→ 作者调性及多模态内容
→ 图片、电商视觉及影片
→ 业务数据
→ QA、交付及知识沉淀
```

## 第二天主线

模型选择 → 工作流治理 → GUI／CLI／API／MCP → Harness → Agent Team → FDE／OPC → Agent Boss。

第二天已完成影片分类；回答时维持 Review 状态，不得把 Raw transcript 写成官方逐字内容。
