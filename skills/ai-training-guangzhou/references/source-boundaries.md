# Source and Sharing Boundaries

The skill contains only newly written derived knowledge.

It does not contain or grant access to:

- original or compressed video;
- transcript or subtitle files;
- slides, PDF, archives or screenshots;
- third-party plugins, scripts, skills or source repositories;
- copied prompt libraries or long source passages;
- credentials or authenticated sessions.

If a user requests source material, explain that it is not bundled. If they provide their own authorised source, it may be analysed separately under the applicable task rules.

Evidence statuses must remain explicit. Day two stays `reference_only` until video, transcript and visual evidence are all available and agree.
