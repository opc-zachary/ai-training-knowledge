# Application Playbooks

## Evidence-led research

1. Define the decision maker and decision.
2. Set object, geography, period and competitors.
3. Define preferred sources and freshness.
4. Collect source metadata with each claim.
5. Separate fact, interpretation and recommendation.
6. Resolve conflicting metric definitions.
7. Produce executive and evidence layers.
8. Run contradiction and missing-evidence review.

## Author voice

1. Use several authorised samples across topics.
2. Identify observation position, attention, value order and judgement.
3. Separate stable identity from platform-specific format.
4. Write must-keep, variable and imitation-trap rules.
5. Draft the new topic from judgement, not an old structure.
6. Review identity and originality separately.

## Visual reverse analysis

1. Define intended output and message.
2. Extract transferable hierarchy, type, light, density and proof method.
3. List non-transferable brand, person, copy, claim and campaign elements.
4. Rebuild the direction around the current product and facts.
5. Compare candidates on proof, fidelity, category fit and original distance.

## E-commerce visual set

1. Audit product, facts, brand and references.
2. Build consumer outcomes, anxieties, situations, objections and proof.
3. Assign five head-image and ten detail-screen roles.
4. Write a picture-solo statement for every output.
5. Review the 15-row plan before generation.
6. Generate independent finals with shared visual DNA.
7. Validate file-level accuracy and set-level diversity.

## AI video

1. Define brief, character bible and scene bible.
2. Plan shots with start/end states and rejection conditions.
3. Approve reference frames.
4. Generate short clips and record model/cost/result.
5. Reject identity, physics, product and continuity failures.
6. Edit only shots with narrative function.
7. Inspect final audio, captions, ratio and playback.

## Business data

1. Preserve and identify source.
2. Build dictionary and quality profile.
3. Record cleaning decisions.
4. Define KPIs.
5. Analyse totals, trends, dimensions and exceptions.
6. Reconcile dashboard with source totals and sample rows.
7. State findings, decisions, risks and missing data.

## Universal QA

Verify correct project and sources, method and changes, output requirements, exact destination and independent readback. If a write outcome is uncertain, reconcile before retrying.
