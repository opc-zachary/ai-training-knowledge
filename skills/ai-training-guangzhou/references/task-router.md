# Task Router

| Request | Primary module | Read next |
|---|---|---|
| Choose an AI product or model | K01 | `day-1.md` model framework |
| Let an Agent work on files | K02 | `templates.md` Agent task |
| Research a brand or market | K03 | `application-playbooks.md` research |
| Analyse platform posts/comments | K04 | `application-playbooks.md` research and insight |
| Continue an author's writing voice | K05 | `application-playbooks.md` author voice |
| Analyse or adapt a visual reference | K06 | `application-playbooks.md` visual reverse |
| Plan e-commerce image sets | K07 | `application-playbooks.md` e-commerce set |
| Plan an AI video | K08 | `application-playbooks.md` video |
| Analyse a business table | K09 | `application-playbooks.md` data |
| Verify delivery | K10 | `templates.md` QA report |
| Explain Harness or Agent Team | Day 2 | `day-2.md`, labelled reference only |

## Compose modules

For a brand launch:

```text
K03 research
→ K04 audience evidence
→ K05 copy and voice
→ K07 visual set
→ K08 video
→ K10 QA and delivery
```

For an operations report:

```text
K02 bounded workspace
→ K09 data analysis
→ K10 reconciliation and readback
```
