# Playbook — E-commerce Visual Set

## Goal

Create five head images and ten detail screens that form one selling system.

## Input audit

| Input | Required check |
|---|---|
| Product images | Shape, colour, packaging, usable angles |
| Facts | Supported benefits, specifications, restrictions |
| Brand | Colour, type, tone, logo rules |
| References | Visual role and rights |
| Channel | Ratio, safe area, text and policy constraints |

## Consumer map

Build five lists:

1. desired outcomes;
2. use moments;
3. anxieties;
4. objections;
5. evidence that creates belief.

## Set architecture

### Head images

| Slot | Job |
|---|---|
| H01 | Core click proposition |
| H02 | Strongest functional proof |
| H03 | Different benefit or scenario |
| H04 | Detail, comparison or mechanism |
| H05 | Audience, trust or objection |

### Detail screens

Use a narrative such as:

```text
D01 hero
D02 situation/problem
D03 core benefit
D04 proof/mechanism
D05 second benefit
D06 scene/use
D07 detail/material
D08 comparison/parameter
D09 trust/objection
D10 close/choice
```

Adapt the sequence to the product; do not force unsupported proof types.

## Unified planning table

Every row includes:

- job;
- picture-solo statement;
- main subject;
- product exposure;
- scene;
- consumer copy;
- fact source;
- reference dimension;
- rejection condition.

Review all 15 rows before generation.

## Generation loop

1. Generate H01 and D01 as direction checks.
2. Review product, message and visual DNA.
3. Correct the plan if the direction is wrong.
4. Generate each final file independently.
5. Validate each output immediately.
6. Review the whole set for repetition and narrative.

## Hard checks

- At least four distinct main visuals across five head images.
- At least seven distinct main visuals across ten detail screens.
- At least four detail screens avoid full packaging dominance.
- No invented price, rating, certification or effect.
- Repeated models remain recognisable but vary pose and camera.
- All requested Chinese text is checked character by character.

## Delivery

Provide independent files, contact sheets, plan, prompt record and validation report. A contact sheet is not a substitute for final files.
