# 兩天課程總覽

## 第一天：把 AI 變成個人生產力

第一天的重點不是背工具名稱，而是建立一條可重複的工作鏈：

```text
業務目標
→ 選擇 Agent、模型及工具
→ 限定工作空間與權限
→ 提供來源與工作方法
→ 產出文字、圖片、影片或數據結果
→ 驗證內容、格式與證據
→ 交付到正確目的地
→ 把成功方法沉澱成 Skill 或工作流
```

### 第一天主要能力

| 能力 | 對應模組 | 可交付成果 |
|---|---|---|
| AI／Agent 認知 | K01 | 工具與模型選擇表 |
| 本機 Agent 操作 | K02 | 有權限邊界的任務規格 |
| 品牌／行業研究 | K03 | 有來源的決策報告 |
| 平台與消費者洞察 | K04 | 痛點、場景及語言地圖 |
| 作者調性與 PR | K05 | 可重用作者調性系統 |
| 圖片控制 | K06 | 有參考角色與驗收條件的視覺 Brief |
| 電商視覺 Skill | K07 | 五張主圖＋十張詳情頁計劃 |
| AI 影片 | K08 | 人物／場景設定、分鏡及生成記錄 |
| 數據分析 | K09 | 數據字典、清洗記錄、儀表板及對帳 |
| QA 與交付 | K10 | 輸入、過程、輸出及目的地證據 |

## 第二天：把個人工作流升級成 AI 組織

第二天課件的主線是由單一 Agent 走向完整工作系統：

```text
模型選擇
→ 工作流與治理
→ GUI／CLI／API／MCP
→ Harness
→ Agent Team
→ FDE／OPC
→ Agent Boss
```

### 兩天之間的關係

| 第一天 | 第二天升級方向 |
|---|---|
| 一個 Agent 完成一件工作 | 把工作放入可治理、可驗證的流程 |
| 用提示詞或 Skill 固化經驗 | 用 Harness 加入工具、記憶、測試與回饋 |
| 一個 Agent 研究或創作 | 用 Agent Team 分工、質疑、審查及彙總 |
| 人負責下指令 | 人成為 Agent Boss，設計角色、權限及驗收 |

## 建議四週學習法

| 週次 | 學習範圍 | 當週成果 |
|---|---|---|
| 第 1 週 | K01–K03 | Agent 任務規格＋品牌研究報告 |
| 第 2 週 | K04–K05 | 消費者洞察＋作者調性系統 |
| 第 3 週 | K06–K08 | 視覺套圖計劃＋五鏡頭影片分鏡 |
| 第 4 週 | K09–K10 | 已對帳儀表板＋完整 QA 報告 |

第二天內容目前仍是課件參考，不應當成已核對的正式逐字教學。
