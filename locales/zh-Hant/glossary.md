# 名詞表

| 名詞 | 本課程中的工作定義 |
|---|---|
| 模型（Model） | 負責推理、語言或媒體生成的底層系統。 |
| 介面（Interface） | 使用模型的 App、網站、CLI 或 API。 |
| 工具（Tool） | Agent 可調用的搜索、檔案、程式或外部 API 能力。 |
| 智能體（Agent） | 接收目標、規劃步驟、使用工具並推進交付的系統。 |
| 對話產品 | 主要逐輪返回答案的產品。 |
| 專用工具 | 聚焦圖片、影片、轉錄等單一能力的產品。 |
| 多模態（Multimodal） | 能理解或生成多於一種媒體。 |
| Token | 模型處理上下文及計價的單位，不等於一個字或一個詞。 |
| 上下文（Context） | 模型在目前任務可使用的資訊。 |
| 提示詞（Prompt） | 給模型或 Agent 的指令及背景。 |
| 系統提示詞 | 將目標、輸入、方法、輸出及邊界固化的可重用指令。 |
| 技能（Skill） | 為重複任務封裝的指令、參考及必要資源。 |
| 工作流（Workflow） | 由輸入走到已驗證成果的 Agent／人工步驟。 |
| 連接器（Connector） | 讓 Agent 讀寫其他系統的橋樑。 |
| MCP | 將工具及上下文提供給 AI 系統的協議模式。 |
| API | 系統之間的程式化介面。 |
| GUI | 圖形使用者介面。 |
| CLI | 命令列介面。 |
| Harness | 包圍模型的工作系統：工具、記憶、規則、測試、回饋及執行環境。 |
| Agent Team | 多個不同角色的 Agent 共同完成一個目標。 |
| Agent Boss | 定義目標、角色、權限、標準及驗收的人。 |
| FDE | Forward Deployed Engineer，深入實際環境連接產品能力與營運需要的角色。 |
| OPC | 課件商業語境中的 One Person Company，以 AI 系統放大個人能力。 |
| 視覺 DNA | 字體、光線、密度、顏色組織及氣氛等可轉移視覺規律。 |
| Picture-solo statement | 遮住全部文字後，畫面本身仍能證明的訊息。 |
| 主圖（Head image） | 電商列表中負責點擊、主張或證據的圖片。 |
| 詳情頁（Detail screen） | 電商長頁敘事中的單一畫面。 |
| 視覺反推 | 把參考圖轉成結構化視覺規格。 |
| 幻覺（Hallucination） | 模型把沒有證據的內容當成事實輸出。 |
| 對帳（Reconciliation） | 把分析結果與來源記錄或獨立總數比較。 |
| 讀回（Readback） | 寫入後重新讀取 exact object，證明實際結果。 |
| 可用率（Usable yield） | 通過審查並真正用於最終交付的生成比例。 |
| 參考狀態（Reference only） | 只由次級結構整理，尚未由對應影片證據驗證。 |
