# 練習與模板

## 初階練習

1. K00：畫出問題擁有人、領域專家、AI 操作者、審查者及測試環境。
2. K01：為五個 AI 產品標示介面、底層模型、工具及 Agent 行為。
3. K02：寫一份限制資料夾、工具、外部目的地及禁止行為的任務規格。
4. K03：把「分析這個品牌」改成五個決策型問題。
5. K04：分析 20 篇獲授權帖子，分開帖子聲明、評論證據及你的解讀。
6. K05：由三篇文章找出兩條高信心及一條暫定作者規則。
7. K06：為三張參考圖指定構圖、人物及場景角色。
8. K07：規劃五張不同職責、至少四種主視覺的主圖。
9. K08：寫五個三秒鏡頭及拒收條件。
10. K09：為一張表建立列數、鍵、空值、重複及指標定義。
11. K10：為一個交付物列出輸入、輸出及目的地證據。

## 四個 Capstone

### A｜客戶研究包

研究 Brief、來源台帳、主張證據表、完整報告、Executive Summary、矛盾審查及 QA。

### B｜作者內容系統

作者調性、三個新主題 Brief、三種不同結構、身份／原創審查及可重用 Skill 規則。

### C｜產品視覺 Campaign

消費者地圖、五主圖／十詳情頁計劃、兩張方向樣本、全套獨立檔案、Set QA 及聯絡表。

### D｜管理儀表板

來源 Hash、數據字典、質量報告、清洗記錄、KPI、五個描述發現、三個異常發現、Dashboard、對帳及決策建議。

## 驗證題

- 兩份市場報告增長率不同：比較期間、地域、類別、總額／淨額及方法。
- 圖片漂亮但產品顏色錯、獎項虛構：分類失敗並決定重生或改 Brief。
- Dashboard 比來源高 3%：檢查重複、篩選、退款、日期、貨幣及 Join。
- API 寫入 Timeout：不可直接重試，先查 exact object 或 request ID。
- 第二天只有課件沒有影片：答案必須保留 `reference_only`。
