## 核心學習主線

```text
理解模型、工具與 Agent
→ 建立安全工作空間
→ 進行有證據的品牌與市場研究
→ 分析平台內容與消費者語言
→ 建立作者調性與內容系統
→ 控制圖片、電商視覺及 AI 影片
→ 清洗與分析業務數據
→ 建立 QA、驗收及交付閉環
→ 進一步升級為 Harness 與 Agent Team
```

## 證據標籤

- `verified_video`：已由第一天影片內容支持。
- `direct_course_mapping`：影片內容與課件主題有直接對照。
- `video_led`：主要來自影片，沒有對應課件檔案。
- `reference_only`：只由第二天課件架構整理，尚未完成影片核對。
