## 核心学习主线

```text
理解模型、工具与 Agent
→ 建立安全工作空间
→ 进行有证据的品牌与市场研究
→ 分析平台内容与消费者语言
→ 建立作者调性与内容系统
→ 控制图片、电商视觉及 AI 影片
→ 清洗与分析业务数据
→ 建立 QA、验收及交付闭环
→ 进一步升级为 Harness 与 Agent Team
```

## 证据标签

- `verified_video`：已由第一天影片内容支持。
- `direct_course_mapping`：影片内容与课件主题有直接对照。
- `video_led`：主要来自影片，没有对应课件档案。
- `video_classified_review`：第二天影片、清理稿及画面已完成分类，仍属 Review。
