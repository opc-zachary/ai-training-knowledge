# 练习与模板

## 初阶练习

1. K00：画出问题拥有人、领域专家、AI 操作者、审查者及测试环境。
2. K01：为五个 AI 产品标示介面、底层模型、工具及 Agent 行为。
3. K02：写一份限制资料夹、工具、外部目的地及禁止行为的任务规格。
4. K03：把「分析这个品牌」改成五个决策型问题。
5. K04：分析 20 篇获授权帖子，分开帖子声明、评论证据及你的解读。
6. K05：由三篇文章找出两条高信心及一条暂定作者规则。
7. K06：为三张参考图指定构图、人物及场景角色。
8. K07：规划五张不同职责、至少四种主视觉的主图。
9. K08：写五个三秒镜头及拒收条件。
10. K09：为一张表建立列数、键、空值、重复及指标定义。
11. K10：为一个交付物列出输入、输出及目的地证据。

## 四个 Capstone

### A｜客户研究包

研究 Brief、来源台帐、主张证据表、完整报告、Executive Summary、矛盾审查及 QA。

### B｜作者内容系统

作者调性、三个新主题 Brief、三种不同结构、身份／原创审查及可重用 Skill 规则。

### C｜产品视觉 Campaign

消费者地图、五主图／十详情页计划、两张方向样本、全套独立档案、Set QA 及联络表。

### D｜管理仪表板

来源 Hash、数据字典、质量报告、清洗记录、KPI、五个描述发现、三个异常发现、Dashboard、对帐及决策建议。

## 验证题

- 两份市场报告增长率不同：比较期间、地域、类别、总额／净额及方法。
- 图片漂亮但产品颜色错、奖项虚构：分类失败并决定重生或改 Brief。
- Dashboard 比来源高 3%：检查重复、筛选、退款、日期、货币及 Join。
- API 写入 Timeout：不可直接重试，先查 exact object 或 request ID。
- 第二天只有课件没有影片：答案必须保留 `reference_only`。
