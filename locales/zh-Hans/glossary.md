# 名词表

| 名词 | 本课程中的工作定义 |
|---|---|
| 模型（Model） | 负责推理、语言或媒体生成的底层系统。 |
| 介面（Interface） | 使用模型的 App、网站、CLI 或 API。 |
| 工具（Tool） | Agent 可调用的搜索、档案、程式或外部 API 能力。 |
| 智能体（Agent） | 接收目标、规划步骤、使用工具并推进交付的系统。 |
| 对话产品 | 主要逐轮返回答案的产品。 |
| 专用工具 | 聚焦图片、影片、转录等单一能力的产品。 |
| 多模态（Multimodal） | 能理解或生成多于一种媒体。 |
| Token | 模型处理上下文及计价的单位，不等于一个字或一个词。 |
| 上下文（Context） | 模型在目前任务可使用的资讯。 |
| 提示词（Prompt） | 给模型或 Agent 的指令及背景。 |
| 系统提示词 | 将目标、输入、方法、输出及边界固化的可重用指令。 |
| 技能（Skill） | 为重复任务封装的指令、参考及必要资源。 |
| 工作流（Workflow） | 由输入走到已验证成果的 Agent／人工步骤。 |
| 连接器（Connector） | 让 Agent 读写其他系统的桥梁。 |
| MCP | 将工具及上下文提供给 AI 系统的协议模式。 |
| API | 系统之间的程式化介面。 |
| GUI | 图形使用者介面。 |
| CLI | 命令列介面。 |
| Harness | 包围模型的工作系统：工具、记忆、规则、测试、回馈及执行环境。 |
| Agent Team | 多个不同角色的 Agent 共同完成一个目标。 |
| Agent Boss | 定义目标、角色、权限、标准及验收的人。 |
| FDE | Forward Deployed Engineer，深入实际环境连接产品能力与营运需要的角色。 |
| OPC | 课件商业语境中的 One Person Company，以 AI 系统放大个人能力。 |
| 视觉 DNA | 字体、光线、密度、颜色组织及气氛等可转移视觉规律。 |
| Picture-solo statement | 遮住全部文字后，画面本身仍能证明的讯息。 |
| 主图（Head image） | 电商列表中负责点击、主张或证据的图片。 |
| 详情页（Detail screen） | 电商长页叙事中的单一画面。 |
| 视觉反推 | 把参考图转成结构化视觉规格。 |
| 幻觉（Hallucination） | 模型把没有证据的内容当成事实输出。 |
| 对帐（Reconciliation） | 把分析结果与来源记录或独立总数比较。 |
| 读回（Readback） | 写入后重新读取 exact object，证明实际结果。 |
| 可用率（Usable yield） | 通过审查并真正用于最终交付的生成比例。 |
| 参考状态（Reference only） | 只由次级结构整理，尚未由对应影片证据验证。 |
