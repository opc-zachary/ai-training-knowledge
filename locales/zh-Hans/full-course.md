# 两天课程总览

## 第一天：把 AI 变成个人生产力

第一天的重点不是背工具名称，而是建立一条可重复的工作链：

```text
业务目标
→ 选择 Agent、模型及工具
→ 限定工作空间与权限
→ 提供来源与工作方法
→ 产出文字、图片、影片或数据结果
→ 验证内容、格式与证据
→ 交付到正确目的地
→ 把成功方法沉淀成 Skill 或工作流
```

### 第一天主要能力

| 能力 | 对应模组 | 可交付成果 |
|---|---|---|
| AI／Agent 认知 | K01 | 工具与模型选择表 |
| 本机 Agent 操作 | K02 | 有权限边界的任务规格 |
| 品牌／行业研究 | K03 | 有来源的决策报告 |
| 平台与消费者洞察 | K04 | 痛点、场景及语言地图 |
| 作者调性与 PR | K05 | 可重用作者调性系统 |
| 图片控制 | K06 | 有参考角色与验收条件的视觉 Brief |
| 电商视觉 Skill | K07 | 五张主图＋十张详情页计划 |
| AI 影片 | K08 | 人物／场景设定、分镜及生成记录 |
| 数据分析 | K09 | 数据字典、清洗记录、仪表板及对帐 |
| QA 与交付 | K10 | 输入、过程、输出及目的地证据 |

## 第二天：把个人工作流升级成 AI 组织

第二天课件的主线是由单一 Agent 走向完整工作系统：

```text
模型选择
→ 工作流与治理
→ GUI／CLI／API／MCP
→ Harness
→ Agent Team
→ FDE／OPC
→ Agent Boss
```

### 两天之间的关系

| 第一天 | 第二天升级方向 |
|---|---|
| 一个 Agent 完成一件工作 | 把工作放入可治理、可验证的流程 |
| 用提示词或 Skill 固化经验 | 用 Harness 加入工具、记忆、测试与回馈 |
| 一个 Agent 研究或创作 | 用 Agent Team 分工、质疑、审查及汇总 |
| 人负责下指令 | 人成为 Agent Boss，设计角色、权限及验收 |

## 建议四周学习法

| 周次 | 学习范围 | 当周成果 |
|---|---|---|
| 第 1 周 | K01–K03 | Agent 任务规格＋品牌研究报告 |
| 第 2 周 | K04–K05 | 消费者洞察＋作者调性系统 |
| 第 3 周 | K06–K08 | 视觉套图计划＋五镜头影片分镜 |
| 第 4 周 | K09–K10 | 已对帐仪表板＋完整 QA 报告 |

第二天内容目前仍是课件参考，不应当成已核对的正式逐字教学。
